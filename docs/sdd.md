# Hospital Risk Velocity (dynamic_rpn) - Software Design Document

## Purpose
Turn a log of incident reports into a daily harm score, and show its velocity and acceleration, a control limit and a rising-trend check. A raw incident count can miss a change in severity; this scores each incident by harm level first (see README, "What it does").

## Scope
In scope: harm weighting, calendar-linear daily series, kinetics, control limit and z-score, a status (Within tolerance, Marginal variance, Outside tolerance, No data), and a one-page Streamlit dashboard. Data are generated by a seeded generator, not loaded. Out of scope: real incident data, clinical decisions.

Synthetic data only. Prototype. Not a medical device. Not for clinical decision-making.

## Contract / interfaces
Two packages under `src/`; the engine has no UI dependency.

Engine `risk_kinematics`:
- `add_harm_scores(df, column="Harm_Level")` (`harm.py`): adds the weight per incident.
- `calculate_risk_kinetics(df, window, sigma)` returns a `KineticSeries` (daily series, mean, std, limit).
- `classify(daily, mean, std, sigma, window)` returns a `StrategicStatus` with a `Tolerance` value.
- `has_rising_trend(daily, run_days=TREND_RUN_DAYS)`; `TREND_RUN_DAYS = 6`.

Dashboard `clinical_risk_dashboard`:
- `sample_data.generate_incidents(...)`: seeded synthetic incidents.
- `presentation`: `status_view`, `status_reason`, `headline`, `momentum_view`, `momentum_lines`, `hotspot`, `status_rule_body`.
- `view`: HTML builders (`header_html`, `kpis_html`, `hero_action_html`, `drivers_how_html`, `footer_html`, `trend_svg`, `stylesheet`).
- `app.py`: Streamlit wiring only. Run `streamlit run app.py` from the repo root (root `app.py` starts it).

## Acceptance criteria
1. Status is derived only by `risk_kinematics`; the dashboard filters and displays.
2. Above the chosen sigma is Outside tolerance; above 0.7 x sigma is Marginal variance; otherwise Within tolerance (README, "The method in brief").
3. A rising trend over the last 6 days can raise Within tolerance to Marginal variance; it never lowers a status and never overrides Outside tolerance.
4. A period too short for a full window reads No data.
5. Every page states: synthetic data, not a medical device.
6. The mmonfar wordmark has an empty square element, and the brand linter finds 0 issues (product gate).
